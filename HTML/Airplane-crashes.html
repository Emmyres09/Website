Airplane Crashes and Fatalities

Power BI analysis of global airplane crash data.

Overview

This project analyzes an “Airplane Crashes and Fatalities” dataset to understand where and how fatal airplane incidents occur around the world. The dashboard focuses on locations, flight routes, aircraft types, and operators, with interactive filters that allow users to explore trends over time.

Data & Tools

  • Data source: Quantum Analytics NG
  • Tools: Power BI for data cleaning, modeling, and visualization.
  • Key fields: Date (Year, Month), Location, Operator, Aircraft type, Number aboard, Fatalities, Ground fatalities.

Dashboard Design

The main Power BI dashboard uses slicers to let users filter crash data by:

  • Year
  • Month
  • Aircraft type
  • Operator

These filters allow stakeholders to drill down into specific time periods, plane types, or operators and see how fatalities and crashes vary under different conditions.

Key KPIs

The dashboard highlights several KPIs to summarize the impact of crashes:

  • Ground Fatalities: Total number of people who died on the ground during crashes.
  • Number of Operators: Count of unique airlines/operators in the dataset.
  • Number of Routes: Count of distinct flight routes in the data.
  • Total Aboard: Total number of passengers and crew aboard across all recorded flights.
  • Total Fatalities: Total number of fatalities both on board and on the ground.

Key Insights

The analysis surfaces several important patterns:

  • Top 5 locations by fatalities: Identified locations with the highest number of fatalities, highlighting regions with the most severe incidents.
  • High‑risk routes: Examined flight routes to see which routes experienced the highest fatalities and how frequently they occurred.
  • Aircraft type impact: Highlighted the top 5 aircraft types by total fatalities, showing which models were involved in the deadliest incidents.
  • Seasonal patterns: Visualized total fatalities by month and quarter to identify any seasonal spikes or patterns in crash severity.
  • Operator patterns: Compared the number of operators by aircraft type to see which combinations appeared most frequently in crashes.
  • Long‑term trends: Tracked total fatalities and total aboard by year to understand whether crash severity has increased or decreased over time.
